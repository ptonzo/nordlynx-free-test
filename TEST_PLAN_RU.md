# Приёмочные проверки NORDLYNX Free Test

- [ ] Репозиторий GitHub имеет видимость Public.
- [ ] GitHub Pages включён через GitHub Actions.
- [ ] Workflow запускается вручную и по расписанию.
- [ ] Сборка прекращается, если доступно менее 20 узлов или менее 5 стран.
- [ ] При провале порога ранее опубликованный сайт не заменяется пустой подпиской.
- [ ] `sub.txt` открывается по HTTPS без авторизации.
- [ ] Happ импортирует подписку и отображает профиль NORDLYNX TEST.
- [ ] Happ показывает узлы и выполняет собственный тест задержки.
- [ ] Проверено подключение хотя бы к одному узлу с каждого тестируемого устройства.
- [ ] Проверено, что повторное обновление подписки заменяет список без дублирования профилей.

**Критерий готовности личного теста:** подписка импортируется в Happ, а минимум 20 узлов прошли TCP-проверку во время сборки. Это не равно гарантии 20 полноценных работающих VPN-соединений.
