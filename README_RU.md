# NORDLYNX VPN — бесплатная тестовая система для Happ

## Что это

Проект не арендует VPS и не запускает собственные VPN-серверы. Он собирает публично опубликованные конфигурации третьих лиц, проверяет TCP-доступность адреса и порта, отбирает не менее 20 узлов с географическими метками минимум из 5 стран и формирует стандартную текстовую подписку Happ.

**Важно:** TCP-проверка не доказывает, что VPN-аутентификация/туннель действительно работают. Страна берётся из подписи публичного узла, а не подтверждается независимой геолокацией. Поэтому число 20 — технический порог отбора, а не гарантия 20 рабочих VPN-серверов для каждого пользователя.

## Бесплатная архитектура

- GitHub public repository — хранение кода.
- GitHub Actions — плановая сборка каждый час.
- GitHub Pages — публикация статической подписки по HTTPS.
- Python 3.12 standard library — сбор, дедупликация, TCP probe и сборка.
- Happ — клиент на Android / iOS / Windows, импорт стандартной URL-подписки.
- Нет VPS, домена, базы данных, Telegram-бота или платежей на тестовом этапе.

GitHub Pages доступен на GitHub Free для публичных репозиториев. Публикация доступна всем в интернете — не добавляйте секреты/персональные данные в репозиторий.

## Источники по умолчанию

1. `https://radarhub.top/v2ray.txt` — V2Ray-совместимый список Free Nodes Radar.
2. `https://raw.githubusercontent.com/ninjastrikers/Nexus-nodes/main/configs/all.txt` — публичный агрегированный список.

Условия, доступность, лицензии и допустимость повторной публикации необходимо проверять у каждого источника. Наличие конфигурации в публичном репозитории само по себе не является разрешением на коммерческую перепродажу или брендирование чужих узлов.

## Установка — один раз

1. Создайте аккаунт на https://github.com/ (бесплатный тариф).
2. Создайте **Public** repository с именем `nordlynx-free-test`.
3. Распакуйте архив и загрузите в репозиторий всё содержимое папки `nordlynx-free-test` (включая скрытую папку `.github`). Удобнее всего: на странице репозитория **Add file → Upload files**, перетащить все файлы и папки.
4. Откройте **Settings → Pages**. В разделе Build and deployment выберите **GitHub Actions**.
5. Откройте вкладку **Actions**, разрешите workflows, если GitHub спросит, и запустите **Update NORDLYNX public test subscription → Run workflow**.
6. Дождитесь зелёного статуса. В workflow summary будет адрес Pages. Обычно подписка доступна по адресу:
   `https://ВАШ-ЛОГИН.github.io/nordlynx-free-test/sub.txt`

Если сборка завершилась ошибкой `Threshold not met`, это означает, что сейчас не набралось 20 TCP-доступных узлов с метками минимум 5 стран. Публикация новой подписки не произойдёт; нельзя вручную снижать порог только ради зелёной галочки.

## Подключение в Happ

1. Установите Happ из официального магазина/источника разработчика.
2. Откройте Happ → `+` → добавление подписки.
3. Вставьте URL Pages вида `https://ВАШ-ЛОГИН.github.io/nordlynx-free-test/sub.txt`.
4. Обновите подписку. Если профиль импортирован, проверьте каждый узел встроенным тестом задержки/подключения.

Файл содержит обычные URI (`vless://`, `vmess://`, `trojan://`, `ss://`, `socks://`) и параметры профиля Happ. Формат подтверждён документацией Happ.

## Что означает «20 одновременно»

Сборка требует 20 узлов, прошедших TCP connect на момент проверки, и минимум 5 географических меток. Узлы могут отключиться через секунду после проверки, быть заблокированы вашим провайдером или не пройти протокольную авторизацию. Чтобы утверждать «20 реально работающих VPN», нужна end-to-end проверка каждого протокола из вашей сети; этот бесплатный пакет её не обещает.

Если в течение очередной сборки порог не выполнен, старый опубликованный Pages-сайт останется нетронутым, так как workflow останавливается до шага публикации.

## Безопасность и коммерческое использование

- Операторы публичных узлов неизвестны и могут видеть IP-адрес источника, DNS/метаданные и незашифрованный трафик. HTTPS защищает содержимое соединения с сайтом, но не делает неизвестный VPN-узел доверенным.
- Не используйте эти узлы для банков, почты, госуслуг, корпоративных систем, паролей и иной чувствительной активности.
- Не продавайте доступ, не обещайте конфиденциальность и не называйте эти машины собственными серверами.
- До коммерческого запуска получите явное разрешение операторов на перепубликацию/перепродажу, подтвердите право на бренд/домен и проверьте применимое законодательство каждой страны.
- Удалите или замените любой источник по запросу владельца или при сомнениях в разрешении на публикацию.

## Локальная проверка

Нужен Python 3.10+:

```bash
python src/build_subscription.py
```

Порог можно переопределить для локального теста переменными окружения, но для публикации рекомендуется сохранить 20 узлов и 5 стран. Скрипт использует только стандартную библиотеку Python.

## Ограничения бесплатной модели

GitHub Pages предназначен для статического хостинга, а не для высоконагруженного коммерческого VPN-сервиса. GitHub может ограничивать злоупотребления и автоматизацию. В репозитории нет пользовательских аккаунтов, биллинга, индивидуальных ключей, лимитов трафика, поддержки пользователей или собственных VPN-узлов.
