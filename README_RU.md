# NORDLYNX VPN — личная тестовая подписка Happ

## Назначение

Бесплатный тестовый агрегатор публично опубликованных конфигураций третьих лиц. Проект не владеет узлами, не управляет ими и не гарантирует их безопасность или постоянную доступность. Не использовать для банков, паролей, корпоративных и иных чувствительных действий. Не продавать и не перепубликовывать чужие узлы без разрешения их операторов.

## Проверка узлов

Сборщик использует sing-box для попытки построить реальный протокольный outbound, поднимает локальный mixed proxy и отправляет HTTPS-запрос через него к api.ipify.org. Затем определяет страну по фактическому egress IP через ipwho.is.

В подписку попадают только узлы, которые прошли всю цепочку:
1. URI удалось разобрать.
2. sing-box принял конфигурацию.
3. sing-box запустил outbound.
4. HTTPS-запрос через локальный прокси успешно завершился.
5. Получен внешний IP и определена его страна.

Это end-to-end проверка с GitHub Actions runner. Она не доказывает доступность из сети пользователя: провайдеры, страны, блокировки и маршруты отличаются. Проверка одноразовая, узел может отключиться сразу после неё. Это не аудит безопасности.

## Географический порог и публикация

Workflow настроен на минимум 20 успешных узлов из минимум 20 разных стран. Ограничение — не более 3 узлов на страну. Страна берётся из GeoIP результата для фактического выходного IP, а не из имени узла.

Если порог не достигнут, сборщик возвращает ошибку до шага публикации. Предыдущая опубликованная подписка на GitHub Pages остаётся без изменений. Не снижайте пороги только ради зелёного статуса. Публичные бесплатные источники могут не содержать столько доступных узлов; поэтому успешная публикация 20 стран не гарантируется.

## Бесплатные компоненты

- GitHub Public repository — код.
- GitHub Actions — почасовой запуск и тесты.
- GitHub Pages — статическая HTTPS-подписка.
- sing-box — протокольная проверка.
- ipwho.is — GeoIP по фактическому egress IP.
- Happ — клиент подписки.

Внешние источники и GeoIP API могут менять доступность, лимиты и условия. Не отправляйте им секреты или персональные данные.

## Запуск

1. GitHub → Actions.
2. Выберите Update NORDLYNX public test subscription.
3. Run workflow → Run workflow.
4. Посмотрите шаги Run unit tests, Install sing-box и Build and end-to-end test subscription.
5. Только при Success и статусе `ok` будет опубликована новая подписка.

URL страницы: https://ptonzo.github.io/nordlynx-free-test/
URL подписки: https://ptonzo.github.io/nordlynx-free-test/sub.txt
Статус последней сборки: https://ptonzo.github.io/nordlynx-free-test/status.json

## Поддерживаемые форматы

Сборщик содержит преобразование VLESS, VMess, Trojan и Shadowsocks URI в sing-box outbound. Не все редкие транспорты/варианты URI поддерживаются. Неподдерживаемые или некорректные записи отклоняются, а не публикуются как «рабочие».

## Ограничения

- 20 стран — жёсткий порог отбора, а не гарантия наличия такого количества бесплатных узлов.
- GitHub Actions выполняет проверку из инфраструктуры GitHub, а не из домашней/мобильной сети пользователя.
- GeoIP может ошибаться или не совпадать с физическим расположением сервера.
- В подписке используются конфигурации третьих лиц; операторы могут наблюдать IP, метаданные и незашифрованный трафик.
- GitHub Pages — только статический хостинг. Здесь нет личных аккаунтов, оплаты, управления собственными серверами или гарантированного SLA.
